# Community conduct

We welcome contributors and users of different backgrounds, identities and experience levels. Be respectful, explain technical disagreements with evidence, and help others participate without embarrassment.

Harassment, discriminatory remarks, threats, personal attacks, unwanted sexual attention, and publishing someone else's private information are not acceptable. Never share merchant credentials or customer data in community discussions.

These expectations apply to this repository's issues, pull requests, reviews and other project spaces. Maintainers may edit or remove harmful content, restrict participation, or close discussions when needed to protect contributors. Decisions should be proportionate to the behavior and its impact.

To report a conduct concern, contact the repository maintainer through an available private GitHub channel. If none is available, open an issue asking for a private contact channel without naming affected people or publishing sensitive details. Security vulnerabilities follow the separate process in [SECURITY.md](SECURITY.md).
